# 识别操作性方法的虚构练习

以下句子完全虚构，用于教学，不是个人项目记录或真实课程摘录。

- 如果多个任务重复使用同一套验证流程，把流程拆成独立 Skill，并在入口规则中引用。这里有适用条件与具体动作，可作为 note 候选。
- 如果只是解释哈希如何计算，内容描述的是机制，适合 concept。
- 某项目昨天执行了三次校验。这是一次性项目事实，不自动变成通用方法。
- 提高质量、认真思考。这些表述缺少可检查的具体动作，不能独立成为方法论。

一份材料可包含多个独立方法，也可只支撑同一方法的多个子知识点。按目标、条件、动作和独立使用价值判断，不按段落数拆页。正式页面仍需要真实、可回读的来源。
