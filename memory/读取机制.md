# Memory 读取机制

## 每轮先查偏好，再按需补充其他记忆

1. 每轮回复用户前必须检索 `偏好/`。根据完整问题和必要前文，提取本轮主题、回复用途、交付形式、客户端与执行场景，查找约束本次回复的偏好；不能先以“本轮不需要历史记忆”为由跳过。涉及工具、文件修改或协作方式的偏好，在对应行动前检索并应用。
2. 通过 [元数据工具](../tools/memory_catalog.md) 查询偏好目录，再根据 [目录导航](索引.md) 判断是否需要经历、项目等其他类别；可以在同一次查询中包含多个目录。工具只读文件头部，先在程序中筛选，再返回候选元数据，不默认加载全量摘要。工具做词面匹配，相关性和同义词由 Agent 判断。
3. 检查候选的标题、标签和摘要；只使用 `active` 且能补充当前任务的条目。有 `scope` 时核对额外适用限制，缺省不视为全局通用。`retired` 仅供历史查询。检查截断提示，未返回的条目不等于不存在。
4. 回读必要候选的正文，确认来源、条件、例外与有效内容。当前上下文已有完整正文时可以复用，但每轮仍须检索并复核适用性；新会话、压缩后或条目有更新时重新读取。摘要用于路由，不能代替执行要求、事实证据和原话；词面命中和标签不证明事实成立。
5. 有具体缺口再沿 `related_ids` 或真实正文链接补读必要关联，依据充分时停止。同一任务可能同时需要偏好、经历、项目等多类记忆，不把最先选择的目录当作唯一边界。
6. 按性质使用：偏好约束协作，原则和决策方式提供用户明确的判断依据，经历、目标、项目、任务提供背景、方向和续接信息。模型归纳的协作经历是经验参考，不变成用户命令或个人原则。
7. 组织回复时核对是否遵守本轮适用的偏好，包括表述顺序、详略、格式、事实边界及交付要求；检索到条目还不等于完成应用。核对当前要求和时效后再使用其他记忆。项目状态、成果和任务完成情况另查实际依据，`updated` 与 `active` 不证明事实仍成立。基础要求以当前生效的 canonical `AGENTS.md` 为准，当前明确要求优先于历史偏好。

偏好查询至少覆盖本轮主题与输出场景。例如本轮调整记忆规则，回复为中文说明：

```bash
python3 tools/memory_catalog.py search '记忆 规则 回复 中文' --category 偏好
```

例如“介绍分销商城项目”，可同时查询项目事实和表达偏好：

```bash
python3 tools/memory_catalog.py search '分销商城 项目介绍 面试口述' --category 项目 --category 偏好
```

关键词不足以表达需求时，可先浏览所选类别的元数据，不必打开全部正文：

```bash
python3 tools/memory_catalog.py search --category 任务 --category 个人目标
```

## 没有命中、冲突与例外

- 未命中或只覆盖部分需求时，先换同义词、补充必要前文中的对象，或省略 `--category` 查七类目录；不因目录选择而遗漏其他类别。
- 偏好查询未命中或无法确认是否覆盖通用回复要求时，省略关键词浏览 `偏好/` 元数据，并处理截断后再判断；不能直接把零命中解释为“没有适用偏好”。浏览时仍只回读必要正文，无需打开全部偏好文件。
- 需要查看某类全部元数据时省略关键词，必要时增大 `--limit`；输出 `truncated=true` 表示结果尚未返回完整。关键词按空格拆分，工具不自动分词或推导同义词。
- 元数据补查仍不足，且用户提及过去内容时，再定向搜索七类目录正文，例如 `rg -n '简历|项目经历' memory/经历 memory/偏好 memory/项目`。零命中不证明从未说过。
- 索引或链接失效时核对真实文件并修复，无法找到时说明不可核验，不声称已读取。
- 当前明确要求优先；“这次例外”只覆盖当前任务。用户说本轮不用历史偏好时遵从，不推定永久停用。
- 相同主题、不同条件可共存，不能只按更新时间决定覆盖。冲突影响结果时先做独立部分，再针对范围追问。
- 用户问记住了什么时，按所问范围查询元数据，再读相关正文回答；不把目录说明、模板和空分类说成已有记忆。
- 新会话或压缩后重新定位导航并判断候选的适用性，不假定以前读过就永远适用。

## 工具与边界

[元数据工具](../tools/memory_catalog.md) 查询只读取条目 frontmatter，返回路径、来源、摘要、适用限制及命中字段；目录导航生成和检查使用全部条目元数据，不读取正文，也不替代语义判断。

```bash
python3 tools/memory_catalog.py --check
```

记忆读取不自动触发 Wiki 检索，Wiki 是否使用按任务与对应 Workflow 判断。维护记忆转 [整理规则](写入机制.md) 和 [提交 Workflow](写入Workflow.md)。
