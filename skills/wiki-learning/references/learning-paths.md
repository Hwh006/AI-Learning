# 学习方向与路线来源

开始学习、学习目标实质变化或需要确定路线来源时读取。方向决定内容怎样组织；NEW、CONTINUE、REVIEW、STATUS 决定本轮做什么，不新增或替换状态枚举。

## 1. 入口判断

| 用户意图与输入 | 学习方向 | 路线的主要依据 |
|---|---|---|
| 提供链接、视频、文件、书籍、课程或粘贴内容，想学习其中知识 | 材料驱动学习 | 指定材料的问题、结构、知识关系和实际正文 |
| “我想学习 AI”“带我学 RAG”等主题请求，没有指定要以哪份材料为主线 | 知识地图驱动学习 | 当前 Map 的领域与专题维度，以及对应 Wiki 正文 |
| 明确要求按 Map 学习，即使附带参考文件 | 知识地图驱动学习 | Map／Wiki 组织整体，文件作为相关参考 |
| 继续、复习或回答当前题目 | 沿用已确定方向 | 恢复实际学习记录，不因消息里出现新术语就重选方向 |

“材料驱动”不表示只读一个来源或只能学一个知识点。一本体系完整的书也属于材料驱动；为其中知识点查 Wiki、补基础或参考其他资料，不自动改成地图驱动。

用户明确把材料作为参考、要求围绕整个主题系统学习时，以整体学习目标为准。只有主线确实不清且会改变范围时才澄清，不能只按附件存在与否机械分类。普通解释问题仍按问答处理，不因出现 AI 等主题名就自动启动教学。

## 2. 材料驱动学习

1. 确认指定正文与目标，按 [材料分类与学习拆解](material-decomposition.md) 分别处理文章、书籍、课程或粘贴内容，展示主线、候选单元及预期能力。
2. 查当前知识库及必要参考资料，补足前置概念、机制、例子、条件或实现缺口。补充用于理解和应用这份材料，不未经用户调整就扩展成整个领域的课程；原文与补充依据分别标明。
3. 按 [诊断与路线规划](diagnosis-and-planning.md) 检查真实基础，先补课并验证，再逐单元教学、练习和纠错；记录逐字讨论。
4. 一篇文章、一个书籍章节或一个课程模块的约定学习范围完成后，按 [讨论原文与归档](discussion-archive.md) 归档实际正文和讨论，接续项目已授权的 Wiki 查重、生成或更新及 Map 同步。

材料中的知识点不一定各新建一页，已有同义 Wiki 应按证据合并。内容校验后将新增或更新知识挂回已有地图的适当分支，地图同步通过后才报告闭环完成；不把“已保存 raw”或“Wiki 已写完”当作地图也已更新。

## 3. 知识地图驱动学习

1. 定位主题范围。 先查当前知识总地图及对应领域／专题 Map。AI 这类宽主题先展示已有主要学习维度，不直接钻进单篇文章；RAG、BM25 等较具体主题只定位相关分支与必要前置，不自动扩成整个 AI 领域。资料位置按 [项目接入](project-integration.md) 或当前宿主实际目录取得。
2. 从 Map 组织、从 Wiki 取证。 读取地图目录与相关分支，沿实际链接回读对应 Wiki。为候选维度核对代表性正文，正式讲解某单元前读取覆盖它的实际内容；标题、链接数量和地图描述不当作知识正文。尚未回读的维度标明待核，不宣称已通读全部 Wiki。
3. 形成跨来源学习要点。 围绕目标，从已核对的概念、方法、方案、比较等页面组织主要问题、关键概念、机制、应用和边界，关联前置依赖。同一知识点分布在多页时合并组织并保留各来源，不机械一页一课，也不把单份材料的目录当整个主题的范围。
4. 展示范围并诊断基础。 简明展示现有地图覆盖的维度、候选单元及预期能力，再用真实回答确定起点。知识地图驱动不等于高级学习；零基础同样先讲必要概念并验证。依据目标和基础安排学习顺序，地图编号不直接等于教学顺序。
5. 聚焦当前专题推进。 宽主题可以规划多个专题，按已有专题档案分别推进；不要求一次读取或考查整个领域。补充文章、书籍或课程只服务当前要点，除非用户改变目标，否则不切回材料主线。两种方向共用理解表达、实践、检验、纠错、手册和逐字记录流程。
6. 处理覆盖缺口。 地图体现当前 Wiki 已组织的范围，不保证外部领域已完整覆盖。若 Map 缺分支，先检索现有 Wiki 判断是否只是导航遗漏；有正文但未挂图、正文不足、尚未核读分别说明。没有相关 Map 时可据现有 Wiki 暂定路线并注明地图缺失；连相关知识也不足时标明缺口，按学习目标补读可靠依据，不把模型临时列的大纲冒充当前地图。无知识库宿主沿用已明确的通用知识降级方式，并说明路线不是来自本地 Map。

## 4. 记录、回流与续学

- 在学习手册路线区注明方向、目标范围、主线依据和补充来源。地图方向记录实际 Map 路径与专题，材料方向记录指定材料及其相关 Wiki；复用现有 `map_ref`、`source_refs` 和依赖字段，不增加必填 JSON 字段或迁移旧记录。材料方向也可以有 `map_ref`，不能仅凭该字段推定学习方向。
- 地图学习以已明确的一个专题或阶段作为讨论归档边界。已有 Wiki 与其原始证据用于引用和回查，不复制成“新正文 raw”再次入库；归档只加入实际新增讨论或新取得的外部材料。清单保留被使用的 Wiki／Map 路径；讨论 raw 可用 `source_wikis` 关联，`source_raws` 只填写确有的新原文。
- 有新增可复用知识、纠正或来源证据时，按既有授权查重并增补适用 Wiki，再同步 Map；没有新增内容时说明复用或跳过，不为每次复习重建来源页和地图。新讨论不能自行升级为已验证事实。
- 材料学习回流 Wiki 并同步 Map 后，后续主题学习应重新核对受影响的分支与正文，可据此完善候选路线。只调整受影响的单元、来源和新目标，不重置其他已学证据，也不把新加入地图的内容标成用户已掌握。
- 新规则不自动重开历史课程。旧记录未注明方向时结合实际请求与已有主线恢复，不根据文件数量或存在 Map 链接擅自切换。
