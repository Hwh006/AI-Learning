# 指定材料的结构、覆盖与教学路线

适用于文章、章节、书籍和课程等已有组织结构的材料。[材料分类与学习拆解](material-decomposition.md) 定义原文骨架、逐节知识清单、术语与步骤等产物；本文件负责将它们呈现为用户能看懂的学习安排，并核对覆盖。两者共享一份清单，不各造一套目录。输出示范见 [完整实例](examples/material-walkthrough.md)。

## 1. 先取得原文，再还原内容骨架

- 先提取实际内容的标题和子标题，保留父子关系、顺序及论述作用，再逐节展开知识结构；网页导航、相关推荐不算正文标题。还需阅读对应正文、图示、代码和条件，不能只列目录名称。
- 为每节识别主要问题、知识点、技术名词、与前后节的关系及作者给出的方法步骤。没有正式标题时，按实际论证关系归纳，注明是教学整理。
- 标明取得范围。缺少章节、图示或附录时不假装已经覆盖；核心缺口先补材料，非核心部分可以标注待补。

用下列表格记录覆盖，放入同专题手册；材料较长时可独立为导航文件并由手册链接。

| 原文章节／父级链 | 主要问题与知识点 | 必要术语／前置 | 学习位置 | 实际进度 |
|---|---|---|---|---|

实际进度区分：未讲、部分讲解、已讲未检验、已有局部掌握证据、明确暂缓。不要把“读过原文”或“写入手册”记为用户已经学过。

标题应全部有去向，正文中的关键术语也要有位置；不是把每个标题都强制拆成一课。作者讨论的实施条件、边界、成本和结果应保留，不能只挑最容易出选择题的知识点。

## 2. 开始时先展示整个学习流程

先展示作者的总体问题、原文章节的简明全貌，以及每节需要理解的主要知识点和名词；不能用“问题→方法→评估”这种通用流程代替原文章节结构。复杂材料可把完整逐节清单放在可读导航中，对话仍要给用户完整高层认知。

再把原文结构转为学习路线，向用户呈现四项：对应原文位置、要学的知识和关键术语、前置依赖或顺序调整、完成后可解释或应用什么。路线不是正文摘要，也不是只有章名的目录。可在原文当前章节前插入必要基础，明确何时回到该节；其余情况下保留作者骨架。

展示知识范围后，可问一次用户对整体范围的熟悉程度，或复用已有手册中具体而可靠的反馈，再决定每个知识点的详略。不能只说“你已有 RAG 记录”便默认所有组成概念都懂。首次在未解释陌生概念前，不出依赖这些概念的摸底题。

上述导航要在连续讲解和出题前出现；时间短时缩小本次覆盖量，不只展示当前小题。原文之外的知识标为前置或补充，不能伪装成作者的章节。

此处展示的是整体导航，不等于已经开始或完成必要基础教学。按[教学层次与进入条件](diagnosis-and-planning.md#教学层次与进入条件)区分基础概念、标准流程与材料新增方法；导航只交代问题、目标和关系，详细流程在相关前置确认后展开。

需要为前置知识调整顺序时，说明对应原文章节及调整理由；回到主线时提示当前原文位置。不能没有说明就用通用专题目录替换作者结构。

## 3. 通过解释确认基础，再决定详略

从当前材料必需的概念出发，先简要解释其含义、作用与一个具体例子，再观察用户能否用自己的话说明或判断关键关系。不要一上来用未解释的技术名词出题。

| 当前知识点的证据 | 后续讲解 |
|---|---|
| 尚无理解，或用户明确不懂 | 先讲是什么、为什么需要、怎样运作，用完整例子检查理解后再出应用题 |
| 理解一部分 | 简要连接已知内容，集中补缺口；不重讲其已能正确说明的部分 |
| 已能正确解释和应用 | 只作简短概括、标明与本文的关系及关键边界，再进入新内容 |
| 基础仍不确定 | 做轻量解释与确认，不连续追问或贴永久能力标签 |

用户原话、已有有效作答可以提供证据；旧手册里出现过名词不能证明用户已经理解。一个大主题学过，不代表其每个组成概念都懂。基础解释后答对不冒充无提示的独立测验。

## 4. 方法要讲成一条完整链路

对方法／技术文章，展开前先给作者问题与方案的整体概览；相关前置已确认后，再沿原文详讲完整链路。至少使用户能回答：

- 原先怎么做，在哪里遇到问题？
- 作者增加或改变了什么？与原流程的连接点在哪里？
- 各步骤用什么输入，做什么处理，产生什么结果？
- 哪些发生在准备阶段，哪些发生在实际使用阶段？材料没有这种分期时不强造。
- 实施还取决于哪些条件？作者的证据支持到哪里？

用同一个贯穿例子追踪主要步骤，避免只有“建索引”“提升相关性”等动作名而没有输入和结果的变化。若用户答错或连续追问暴露整条关系不清，应重讲相关链路或补前置，不不断换同结构选择题。

## 5. 指标与术语的权重

- 核心术语按首次使用的位置解释，说明属于对象、算法、模型、步骤、索引结构还是评测量，减少因同样“会打分”而混淆角色。
- 实验数字在作者的实验／结果章节中解释，够理解作者证据、比较口径和边界即可。除非用户目标是评估方法或材料本身以测量为核心，不单独扩成数轮指标考试。
- 一个小例子、指标或提醒不能挤掉标题对应的主要机制和步骤；实现细节与延伸答疑应标为补充并回到主线。

## 6. 旧档案、暂停与验收

复用旧档案前比对材料来源、章节和知识点；旧答题证据只支持当时的问题范围。用户说“整体仍没懂”时，复核导航与覆盖，不用局部掌握标志反驳用户，也不删除历史答案。

若暂停以修正路线，保持暂停，记录新路线及旧待答项的处理方式。恢复时先按已修订的目标重新导航；旧题可保留为暂缓，不能自动把用户拉回已被明确降权的指标考试。变更状态与待答项时遵守状态契约。

材料学习的收尾同时核对：核心章节和术语是否覆盖，用户能否讲清作者的问题、方案与主要步骤，以及练习证据支持的实际范围。部分概念通过不能代替整篇内容覆盖；新准备的导航、解释与手册内容不计已经完成教学。
