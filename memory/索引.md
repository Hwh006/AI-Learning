# 记忆目录导航

本页说明各目录的用途和调用时机，不汇总具体记忆的标题、标签、摘要或正文。每轮回复前必须检索偏好并按适用要求回复；其他目录按当前任务需要选择，再通过元数据查询定位条目。
目录用于缩小检索范围；未命中或分类不明确时扩大查询，不把目录当作唯一边界。空目录不代表已有记忆。

| 目录 | 存什么 | 什么时候读取 | 有效条目 | 已停用 |
|---|---|---|---|---|
| [经历/](经历/) | 亲历、处境、想法、外部观察及协作经验 | 回答个人背景、写简历或参考过去处理经验时 | 0 | 0 |
| [偏好/](偏好/) | 回复、表达、交付及协作的核心要求 | 每轮回复前必须检索并应用适用偏好；执行方式偏好在行动前应用 | 0 | 0 |
| [个人原则/](个人原则/) | 用户明确的判断准则、支持经历与例外 | 决策需要参考用户自己的原则时 | 0 | 0 |
| [个人目标/](个人目标/) | 用户明确的长期方向及约束 | 制定计划、安排优先级或讨论长期选择时 | 0 | 0 |
| [项目/](项目/) | 项目背景、职责、方案、结果及权威资料入口 | 讨论具体项目、准备面试或核对本人贡献时 | 0 | 0 |
| [任务/](任务/) | 需要跨会话保留的行动、进度与下一步 | 继续此前工作、查询待办或恢复任务时 | 0 | 0 |
| [决策方式/](决策方式/) | 一类情境中的关注因素、判据与取舍 | 遇到相似选择，需要参考过去判断方式时 | 0 | 0 |
